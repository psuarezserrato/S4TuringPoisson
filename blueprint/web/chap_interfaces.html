Definition 2.1 Finite Turing machines and halting with an output window
✓
#

Lean declarations

  • S4TuringPoisson.FinTM0
  • S4TuringPoisson.HaltsWithWindow

A FinTM0 is a Mathlib Turing.TM0 machine with finite alphabet \(\Gamma \) and finite state set \(\Lambda \). \(\mathrm{HaltsWithWindow}(M,t,k,w)\) says that \(M\) started on tape \(t\) reaches a terminal configuration whose tape agrees with \(w\) on the cells \([-k,k]\).

Definition 2.2 Turing complete self-map
✓
#

Uses

  • Definition 2.1

Lean declarations

  • S4TuringPoisson.TuringCompleteWitness
  • S4TuringPoisson.IsTuringComplete

\(\varphi \colon X\to X\) is Turing complete if there are points \(p_{M,t}\) (depending only on \((M,t)\), lying in a continuous injective disk chart with computable \(2^{-m}\) rational approximations) and nonempty open sets \(U_{M,k,w}\) (depending only on \((M,k,w)\), avoiding \(p_{M,t}\) whenever the initial configuration is not terminal) such that \(\exists n,\ \varphi ^n(p_{M,t})\in U_{M,k,w} \iff \mathrm{HaltsWithWindow}(M,t,k,w)\).

Lemma 2.3 Turing complete maps are not the identity
✓
#

Uses

  • Definition 2.2

Lean declarations

  • S4TuringPoisson.IsTuringComplete.ne_id

If \(\varphi \) is Turing complete then \(\varphi \neq \mathrm{id}\).

Proof ▶

Apply the witness to a two-state machine that halts after one step.

Theorem 2.4 Undecidability of orbit reachability
✓
#

Uses

  • Definition 2.2

Lean declarations

  • S4TuringPoisson.IsTuringComplete.undecidable_orbit_reachability

For a Turing complete \(\varphi \), reachability of a fixed nonempty open set from computably approximable points is recursively enumerable but not decidable.

Proof ▶

Reduce the halting problem of Mathlib’s partial recursive codes to orbit reachability, via a universal halting machine.

Lemma 2.5 Transfer along open embeddings
✓
#

Uses

  • Definition 2.2

Lean declarations

  • S4TuringPoisson.IsTuringComplete.transfer

Turing completeness of a disk map transfers to any map that agrees with it on an open product \(B_0\times D\) embedded in a larger space.

Proof ▶

Push the encoded points and open sets forward along the embedding.

Definition 2.6 Positive volume form
✓
#

Lean declarations

  • S4TuringPoisson.PositiveVolumeForm

A nowhere-vanishing smooth top form together with its finite Borel measure, positive on nonempty open sets, such that pullback invariance implies measure preservation.
