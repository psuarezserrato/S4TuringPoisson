1 Status and conventions

This blueprint describes the Lean 4 formalization of P. Suárez-Serrato, Hamiltonian and Turing complete flows on smooth \(4\)-manifolds (S4TCdiffeo-Aug-2026.tex), together with the smoothing theorem of Cardona–Miranda–Peralta-Salas–Presas (CMPP21, Thm. 5.2) on which it depends. All nodes carrying \leanok are proved in Lean (toolchain v4.36.0, Mathlib and TauCeti v4.36.0) and depend only on propext, Classical.choice and Quot.sound.

The main results (??) carry no hypotheses. The class HasCMPPCantorCirculationHamiltonians, which earlier versions assumed, is now an instance (theorem 7.5). The four-manifold corollary (theorem 8.5) is stated for every compact Hausdorff smooth \(4\)-manifold carrying an AdmitsWrinkledOrBrokenLefschetzFibration structure (definition 4.5); the paper’s version for every closed oriented \(4\)-manifold additionally needs the existence of that structure, which is not formalized (??).
