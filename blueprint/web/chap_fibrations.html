Definition 4.2 Wrinkled and broken Lefschetz fibrations
✓
#

Uses

  • Definition 4.1

Lean declarations

  • S4TuringPoisson.WrinkledFibration
  • S4TuringPoisson.BrokenLefschetzFibration

A WrinkledFibration is a smooth map \(f\colon M\to N\) with a disk-shaped open region of regular values over which \(f\) is smoothly trivial with compact surface fiber. It places no constraint on the critical points; BrokenLefschetzFibration adds the requirement that every critical point is a Lefschetz point or an indefinite fold.

Theorem 4.8 Existence of the fibration structure (external input)
#

Uses

  • Definition 4.5

Every closed oriented smooth \(4\)-manifold admits an AdmitsWrinkledOrBrokenLefschetzFibration structure. The paper cites Gay–Kirby and Lekili. Because WrinkledFibration does not constrain singularities, an elementary local construction (an embedded \(D^2\times S^2\) in a coordinate ball) may suffice. Not formalized.
