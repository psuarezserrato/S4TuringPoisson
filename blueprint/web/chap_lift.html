Theorem 5.4 Componentwise Moser volume conjugation on compact \(4\)-manifolds
✓
#

Uses

  • Definition 2.6
  • Definition 3.3

Lean declarations

  • S4TuringPoisson.MoserVolume
  • S4TuringPoisson.MoserVolume.ofPositivelyCooriented

For any two positively co-oriented smooth positive volume forms \(V_0,V_1\) on a nonempty compact Hausdorff smooth \(4\)-manifold \(M\) (without assuming connectedness), there is a diffeomorphism \(\psi \colon M\simeq _m M\) preserving each connected component \(C\) with \(\psi ^*V_1|_C = c_C\cdot V_0|_C\) (\(c_C{\gt}0\)); conjugating any component-preserving \(V_1\)-preserving diffeomorphism \(\overline{d}\) to \(d_{\mathrm{exact}}=\psi ^{-1}\circ \overline{d}\circ \psi \) preserves \(V_0.\Omega \) and \(V_0.\mu \) identically.

Proof ▶

Apply TauCeti’s top-degree de Rham integration isomorphism and time-dependent Moser flow on each clopen connected component of \(M\).
