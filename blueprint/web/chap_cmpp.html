Theorem 6.9 Hamiltonian realization of reversible shifts
✓
#

Uses

  • Theorem 6.8
  • Lemma 6.6
  • Lemma 6.2
  • Definition 6.4

Lean declarations

  • S4TuringPoisson.CMPP.exists_autonomous_hamiltonians_realizing_reversibleTM
  • S4TuringPoisson.hasCMPP_of_simulator

The shift of every reversible machine is realized exactly on the Cantor set by finitely many autonomous Hamiltonians supported in the ball of radius \(17/20\). Consequently every universal reversible simulator yields an inhabitant of the CMPP class.

Proof ▶

On each source block the shift is affine (G0); apply the relocation theorem.
